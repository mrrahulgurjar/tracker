# Protocol 90: Cyber Security & Discipline Command Center

A high-tech cyber-terminal web application engineered for winter discipline, cyber security fundamentals, and achieving the non-negotiable target of earning ₹5,000/month flat rent independence in Jaipur.

## Features
- **Obsidian Cyber-Terminal UI:** High contrast dark-mode with live Jaipur IST clock and Day X/90 tracker.
- **Rent Independence Target Meter:** ₹5,000 progress bar with micro-ledger for income entries.
- **Jaipur Winter Routine:** 11 time-blocked non-negotiable checkpoints.
- **Iron Guardrails:** Anti-gaming, zero doom-scrolling, and deep work switches.
- **Cyber Curriculum & Lab Tracker:** OverTheWire Bandit (0-25), Networking Mastery, TryHackMe Rooms, and Proof-of-Work walkthroughs.
- **Terminal Logger:** Styled Linux terminal for committing daily struggle and breakthroughs.
- **Sunday Revision Mode & Full LocalStorage Persistence** (with JSON Export/Import).
